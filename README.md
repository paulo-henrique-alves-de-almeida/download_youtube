# ▶ Download Youtube
Um programa simples para baixar vídeos e músicas do Youtube sem utilizar sites ou programas de terceiros. Feito em Python.

## 💻 Terminal
A primeira versão do programa é feita utilizando apenas o terminal. Focado na leveza e agilidade.

## ✨ Interface Gráfica
Interface feita em [Flet](https://flet.dev/) para permitir ser compilado para vários dispositivos.

## 🔩 Dependências
Esse aplicativo precisa de algumas coisas para funcionar.

- A conversão de vídeos para o formato `.mp3` é feita utilizando o software livre [FFmpeg](https://www.ffmpeg.org/).

### 📚 Bibliotecas
São utilizadas as bibliotecas:
- yt-dlp
- flet
